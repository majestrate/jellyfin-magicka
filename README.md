# Workflow

`uwu`

## Building

build requirements:

* git
* GNU make
* podman

set up build environment (one time):

    $ git submodule update --init --recursive
    $ make setup

compile:

    $ make compile

## running

to run:

    $ make up

to stop:

    $ make down
